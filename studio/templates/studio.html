Keyboard shortcuts

Select a pipe, then press X, Y or Z to extend in a positive direction; Shift + X, Y or Z for a negative direction. Valid ends and colours are offered when a choice is needed. The H checkbox applies to new pipes.

Ctrl/Cmd + Z: undo · Ctrl/Cmd + Y or Shift + Ctrl/Cmd + Z: redo · Delete/Backspace: delete selected pipe or cube (with its connected pipes) · Escape: clear selection · F: fit view. Shortcuts pause while typing.

LOCAL COMPILATION

Generate a Stim circuit

Compile the current graph and your selected observables on this computer.

Nominal code distance: 3. Larger scales require more time and memory.

Temporal height

Stabilizer rounds per block = a × k + b, excluding initialization and final measurement. Default: 2k − 1.

Noise model

Each rule may apply several channels after an operation. Zero channels and zero result flip explicitly mean noiseless. Every circuit operation needs a matching rule. Gate rules take precedence over general rules.

Detectors and database

Values ≤ 0 disable detector computation in this engine. Default: 2.

Named JSON databases are stored locally in instance/studio/databases. Reuse a name to share cached detectors between runs. Import a TQEC JSON database below; each completed cached run offers a database download.

Python API coverage

These controls cover the installed compile_block_graph and generate_stim_circuit parameters: convention, observables, block_temporal_height, k, noise_model, manhattan_radius, detector_database, database_path, do_not_use_database and only_use_database. Database paths are managed through local names and JSON import/export. Custom convention builders and arbitrary NoiseModel subclasses still require Python. Simulation and decoding are separate workflows.

The custom noise editor exposes all six NoiseModel constructor fields and NoiseRule channels / result flips. Vector-valued Pauli channels are not supported by this installed NoiseRule implementation. Compiler limitations still apply to each graph and convention.

For custom noise, every rule is multiplied by p / the custom noise reference p above. All resulting probabilities must remain ≤ 1.
